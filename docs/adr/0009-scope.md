# 0009 Scope of this release

**Status:** Proposed · **Issue:** #5

## Decision

This release delivers Iteration 1: accounts, courses and enrollment by term, the course library with
uploads and extraction, the tiered tutor, and the admin tools needed for the demo.

**Out of this release:** Iteration 2 and 3 features from the proposal, and the mobile client.

## Consequences

- A story that only an out-of-scope feature needs is moved to a later milestone, not half-built.
- The web client is responsive, so phones are still usable through the browser.
